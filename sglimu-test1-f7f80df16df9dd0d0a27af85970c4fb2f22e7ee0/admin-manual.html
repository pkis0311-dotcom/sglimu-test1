2. 제품 정보 관리 (등록/수정)

쇼핑몰에 판매될 제품의 데이터베이스를 관리합니다. 단일 제품 등록뿐만 아니라 상세 사이즈/색상별 가산 가격 및 썸네일 업로드를 지원합니다.
새 제품 등록 팝업 * 필수 항목
🎨 화이트: +0원 | 🎨 블랙: +150,000원
  • 새 제품 등록: 우측 상단의 [새 제품 등록]을 클릭한 후 제품명, 카테고리, 대표 가격, 썸네일 이미지를 입력합니다.
  • 안전장치 밸리데이션: 필수값인 제품명과 카테고리가 누락된 경우 저장이 차단되며 경고 메시지가 표시됩니다.
  • 세부 옵션 가산 설정: 단일 제품 하위에 다수의 컬러나 사이즈를 생성하고 옵션별 추가 가격(예: 블랙 추가 시 +150,000)을 매핑할 수 있으며, 이 정보는 제품 상세 화면에 자동 연동됩니다.
  • 재고 보호: 제품 정보 창에서 임의로 재고를 임의 수정할 수 없습니다. 재고 변경은 [입/출고 등록] 메뉴를 통해서만 트래킹되도록 잠금 처리되어 있습니다.

4. 전화 발주 등록/재고 차감

쇼핑몰이 아닌 유선(전화)으로 인입된 오프라인 발주를 수동으로 등록하고, 출고 수량만큼 DB 재고를 자동으로 차감 기입하는 핵심 장치입니다.
전화 발주 신규 등록 모달
  • 담당자 고정 잠금(보안 강화): 발주를 등록하는 행정 담당자의 투명성 확보를 위해, 현재 로그인 중인 관리자의 성함(이메일 ID 포함)이 **[담당자 성함] 칸에 자동으로 입력되며 임의 수정할 수 없도록 회색 잠금(ReadOnly) 처리**됩니다.
  • 재고 연동 자동 출고: 전화 발주가 저장되는 순간, 선택된 상품들의 수량만큼 `products` 테이블의 실시간 재고가 자동으로 차감 계산됩니다.
  • 변동 로그 생성: 재고가 차감됨과 동시에 `inventory_logs` 테이블에 어떤 관리자(담당자 성함)가 어떤 사유(예: 전화발주 #42)로 몇 개의 수량을 출고시켰는지 자동으로 이력 로그가 생성되어 기록됩니다.

8. 카테고리 구성 자동 관리

쇼핑몰의 대분류, 중간분류, 소분류 카테고리를 설정합니다. 순서 변경이나 분류의 추가/삭제가 즉시 서버로 반영되는 지능형 저장 기능이 포함되어 있습니다.
  • 직관적인 순서 드래그앤드롭: 드래그 핸들()을 잡고 원하는 분류의 위아래 순서를 스왑(Swap)하면, 연동된 순서 번호(Order Badge)가 자동으로 재조정됩니다.
  • 카테고리 구성 실시간 자동 저장(Auto-save):
    • 기존의 수동 [설정 영구 저장] 버튼을 매번 눌러야 했던 번거로움을 완전히 해결했습니다.
    • 새 대분류/중분류/소분류를 **추가**했을 때, 특정 분류를 **수정**하여 반영했을 때, 마우스 드래그로 **순서를 변경**했을 때, 카테고리를 **삭제**했을 때 **자동으로 즉각 DB에 저장 완료**됩니다.
  • 안전장치(Defensive Setup): 데이터 손상으로 특정 분류 객체가 유실되어도 스크립트 내부에서 즉시 안전한 빈 카테고리를 구성하여 에러 발생으로 인한 어드민 셧다운을 방지합니다.
